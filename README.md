
# Adaptive Benchmarking and Selection of QEM Techniques for Noisy Quantum Circuits

This repository contains the literature and supporting reference materials for a research project focused on adaptive benchmarking and the selection of quantum error mitigation (QEM) techniques for noisy quantum circuits.

The project studies how different QEM methods perform under realistic noisy conditions and explores how suitable error mitigation strategies can be selected based on circuit characteristics, noise profiles, and practical trade-offs.

## Project Overview

Quantum hardware is inherently noisy, and this noise can significantly distort the results of quantum computations. Quantum error mitigation (QEM) is a set of techniques designed to reduce the impact of noise without requiring full fault-tolerant quantum computing.

This project focuses on:

- benchmarking QEM techniques under noisy conditions
- comparing mitigation methods across different circuit structures
- adaptive selection of QEM methods based on circuit and noise characteristics
- evaluating the trade-offs between accuracy, resource usage, and computational overhead
